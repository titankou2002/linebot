系統設定與常見問題 Q&A 手冊

磁磚 AI 智能客服系統 · 設定與管理員操作指南

一、 LINE 官方帳號相關設定

Q1. 如何找到 Channel Access Token (TOKEN) 及 Channel Secret？

請依照以下步驟在 LINE 開發者後台取得設定金鑰：

  1. 前往並登入 LINE Developers Console。
  2. 在 Provider 中選擇您的機器人專案，並點選進入對應的 Messaging API Channel。
  3. 取得 Channel Secret：
    • 切換至 Basic settings 分頁。
    • 向下滾動，即可在「Channel secret」欄位看到一串英數混合金鑰並進行複製。
  4. 取得 Channel Access Token：
    • 切換至 Messaging API 分頁。
    • 拉到頁面最下方，找到「Channel access token (long-lived)」欄位。
    • 點擊 Issue 按鈕即可產生並複製此 Token。
⚠️ 重要提醒：Channel Access Token 的時效很長，請妥善保存。若重複點擊 Issue 會生成新的 Token，舊的 Token 將會在數小時後失效，請注意。
Q2. 如何設定並貼上 Webhook URL？

設定 Webhook URL 能讓 LINE 收到訊息時通知您的 Google Apps Script 後端系統：

  1. 進入 LINE Developers Console 的 Messaging API 分頁。
  2. 找到 Webhook settings 區塊。
  3. 點選 Edit 按鈕，在 Webhook URL 欄位中貼上您的 GAS 部署網址（格式應為 https://script.google.com/macros/s/.../exec）。
  4. 貼上後點選 Update。
  5. 重要：將下面的 Use webhook 開關切換為啟用狀態（開關顯示為綠色）。
  6. 可以點擊 Verify 按鈕，若出現 Success 即代表連線設定完全正確。
Q3. 在 LINE 後台需要開啟哪些功能？

為了使機器人可以正常加入群組聊天並回覆，需調整以下設定：

  • 開啟群組權限：在 Messaging API 分頁下方，找到 Allow bot to join group chats，將其設定為 Enabled（這樣機器人才能被拉進業務群組中）。
  • 停用官方預設自動回覆：
    1. 點選頁面中的 LINE Official Account Manager 連結進入 LINE 官方管理後台。
    2. 前往右上角「設定」 -> 左側「回應設定」。
    3. 回應模式：選擇「聊天機器人」。
    4. 詳細設定中的「自動回應訊息」：設定為「停用」（否則當使用者說話時，LINE 官方會隨機自動回覆，干擾 AI 回答）。
    5. 詳細設定中的「Webhook」：設定為「啟用」。

二、 Google 試算表與雲端硬碟權限設定

Q4. 如何提供並開啟 Google 試算表 / 雲端硬碟資料夾的權限？

為使 AI 系統能即時讀寫您的試算表（查庫存、寫保留單）與讀取產品圖庫，必須開放共用權限：

  1. 取得網址連結：開啟您的 Google 試算表或雲端硬碟圖庫資料夾，直接複製瀏覽器上方網址列的完整 URL。
  2. 開啟共用權限：
    • 點選右上角的「共用」按鈕。
    • 在下方「一般存取權」區塊，將原本的「限制」改為「知道連結的任何人」。
    • 右邊角色權限：試算表（Sheets）請改為「編輯者」，以利系統寫入保留單；圖庫資料夾請保持為「檢視者」即可。
    • 點選「複製連結」後，將連結提供給系統管理員即可。
🔒 安全共用選項：若基於內部資料安全不希望開放「知道連結的任何人」，可以請技術人員提供 Google 雲端服務帳號（Service Account Email，例如：xxx@developer.gserviceaccount.com），您只需將該 Email 加為共用名單的「編輯者」即可，無需公開連結。

三、 客戶白名單申請與網頁操作

Q5. 如何新增與審核客戶白名單？

為了防範商業機密外流，系統設有白名單限制，您可以透過以下兩種方式進行權限管理：

方法 A：在 LINE 業務群組內一鍵核准（最推薦，手機即可操作）

  1. 當外部客戶或新業務加入 LINE 官方帳號並嘗試查詢時，系統會自動往您的內部業務群組發送一張「新用戶審核申請卡片」（Flex Message）。
  2. 卡片上會顯示該用戶的 LINE 暱稱。
  3. 內部管理員或負責業務只需要在群組中，直接點選卡片上的「核准為業務」或「核准為經銷商」按鈕。
  4. 點擊後，系統會自動在後台新增該用戶，該客戶隨即會收到核准通知，即可立刻在 LINE 上開始查詢。

方法 B：在 Google 試算表後台手動新增

  1. 打開與機器人綁定的 Google 試算表，切換到名為「白名單」的分頁。
  2. 直接在表格最下方新增一列，填入對方的：
    • LINE User ID（可從對話紀錄分頁中複製新用戶的 ID）
    • 公司名稱
    • 姓名
    • 權限等級（填入：業務 / 經銷商 / 客戶）
  3. 填寫完畢即完成，不需重啟系統，下次該用戶在 LINE 發送訊息時即可自動套用新權限。
